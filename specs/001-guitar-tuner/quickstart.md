# Quickstart Validation: Guitar Tuner Mobile App

Runnable guide for validating the feature after implementation. For entity details see
[data-model.md](./data-model.md); for interface rules see [contracts/](./contracts/); for the
full requirement set see [spec.md](./spec.md).

## Prerequisites

| Tool | Version |
| --- | --- |
| Node.js | 20 LTS or newer |
| npm | 10+ |
| Java JDK | 17+ (Android builds) |
| Android Studio + SDK | API 34 platform, API 24 minimum |
| Xcode | 15+ (iOS, macOS only) |
| Chrome/Edge | Current (web E2E and fake audio device) |

A physical Android phone is required for the microphone-lifecycle scenarios; emulators do not
reliably reproduce permission revocation or background audio behavior.

## Setup

```bash
npm ci
npx cap sync
```

Platform projects exist only after the first add:

```bash
npx cap add android
npx cap add ios      # macOS only
```

## Run

| Target | Command | Expected |
| --- | --- | --- |
| Web dev server | `npm start` | App loads at `http://localhost:4200`, no microphone prompt |
| Unit tests | `npm test` | All Vitest suites pass, including the pitch-fixture table |
| E2E (web) | `npm run e2e` | Playwright runs with fake audio and passes |
| Android device | `npx cap run android` | App installs and launches with no network permission |
| Production web | `npm run build` | Static bundle in `www/` with the CSP applied |

## Fixtures

`tests/fixtures/` contains deterministic WAV tones generated by
`tests/fixtures/generate-fixtures.mjs`:

| Fixture | Frequency | Purpose |
| --- | --- | --- |
| `e2.wav` | 82.407 Hz | Standard low E |
| `a2.wav` | 110.000 Hz | Reference string; in-tune journey |
| `between-strings-220.wav` | 220.000 Hz | Ambiguous G3/B3 band |

Run `node tests/fixtures/generate-fixtures.mjs` to regenerate them. The unit-test
suite synthesises sines, plucks, and noise in memory, so it needs no files.

## Validation Scenarios

| # | Scenario | Steps | Expected |
| --- | --- | --- | --- |
| 1 | No prompt at launch | Cold start, wait 10 s | No permission dialog, no OS microphone indicator |
| 2 | Rationale before prompt | Tap Start | Explanation appears before or with the OS prompt |
| 3 | In tune | Play `a2.wav` | Note A2, 110.0 Hz detected, 110.0 Hz target, 0 ¢, "In tune", needle centered |
| 4 | Flat | Play `a2-flat-15.wav` | ≈ −15 ¢, "Flat", needle left of center |
| 5 | Sharp | Play 111 Hz tone | ≈ +16 ¢, "Sharp", needle right of center |
| 6 | Far off | Play `e2-sharp-152.wav` | ≈ +152 ¢, "Sharp", needle pinned at the right edge, target E2 |
| 7 | Between strings | Play `between-g3-b3.wav` | "Between strings", both G3 and B3 with ±200 ¢, needle centered and dimmed, no string selected |
| 8 | Ambiguity boundary | Play 98.0 Hz | "Between strings" (inclusive boundary), not a single Flat/Sharp target |
| 9 | Silence | Stop the tone, wait 1 s | "Listening…" within 500 ms, no fabricated note |
| 10 | Deny permission | Revoke mic permission in OS settings, tap Start | Explanatory screen, "Open settings" action, app still browsable |
| 11 | Release on stop | Start, confirm OS mic indicator, tap Stop | Indicator off within 1 s, readouts cleared |
| 12 | Release on background | Start, press Home | Indicator off within 1 s; returning shows idle and requires Start |
| 13 | Reference pitch | Set A4 to 445 Hz, play `a2.wav` | Target becomes 111.3 Hz, offset ≈ −20 ¢, no stale 110.0 |
| 14 | Tolerance | Set tolerance to 20 ¢, play `a2-flat-15.wav` | Now "In tune", center zone visibly wider |
| 15 | Mode switch mid-session | Start in Auto, switch to Manual, tap string 5 | Target locks to A2 without restarting capture |
| 16 | Chromatic | Switch to Chromatic, play `a2.wav` | A2, 110.0 Hz, 0 ¢, no string context |
| 17 | Preset switch | Select Drop D, then DADGAD | String list and targets update immediately; last choice persists after restart |
| 18 | Custom tuning | Create "Open C" (C2 G2 C3 G3 C4 E4), save, restart | Present in picker, targets correct, name preserved |
| 19 | Offline | Enable airplane mode, cold start | Full tuning session works; no network activity |
| 20 | No egress | Inspect Android manifest; monitor traffic | No `INTERNET` permission; zero outbound requests |
| 21 | Theme | Toggle light/dark | Whole app updates immediately and persists after restart |
| 22 | Screen reader | Enable TalkBack/VoiceOver, play A2 then a detuned tone | State announced on change; gauge exposes note, cents, and state |
| 23 | Reduced motion | Enable OS reduced motion, change target | Needle snaps without sweeping or fading |

## Automated Checks

```bash
npm test                 # DSP fixtures, selector truth table, state machine, storage
npm run lint             # strict TypeScript (the DSP boundary is asserted by npm test)
npm run e2e              # Playwright: scenarios 1-9, 13-17, 21
```

Scenario 20 is also asserted in CI by a manifest test that fails if `android.permission.INTERNET`
appears in `android/app/src/main/AndroidManifest.xml`.

## Implementation Gate Results (2026-10-22)

| Gate | Command | Result |
| --- | --- | --- |
| Type check | `npm run lint` | PASS — no diagnostics (`tsc -p tsconfig.app.json --noEmit`) |
| Unit and privacy | `npm test` | PASS — 10 files, 88 tests |
| Browser journeys | `npm run e2e` | PASS — 13 Playwright tests in Chromium with a fake microphone |
| Production build | `npm run build` | PASS — `www/` emitted, pitch worker bundled, 473 kB initial (125 kB gzip) |
| Native sync | `npx cap sync` | PASS — Android and iOS assets and plugins copied |

The automated journeys cover all seven user stories: A2 in tune, 220 Hz "Between
strings", manual lock plus nearest-string hint, chromatic mode, tuning
persistence, custom tuning create/restart/delete, reference-pitch recomputation,
sub-second Stop, and release on navigation.

Not executed in this environment, and therefore still open: physical-device
microphone release and OS indicator checks (scenarios 10-12), airplane-mode and
zero-egress verification on device (19-20), TalkBack/VoiceOver and reduced-motion
device checks (22-23), a mid-range Android performance profile, and signed
release builds.

## Troubleshooting

| Symptom | Likely cause | Fix |
| --- | --- | --- |
| `getUserMedia` undefined | Non-secure origin | Serve over `https://` or `localhost` |
| Prompt never appears on Android | `RECORD_AUDIO` missing from the manifest | Re-run `npx cap sync android` |
| Needle jitters at the top of the range | Window too long for the frame rate | Confirm 4096/1024 configuration and Worker frame drops |
| Octave errors on low E | Clarity gate disabled or window shortened | Restore `clarity ≥ 0.85` and 4096 samples |
| iOS silent after background | AudioContext suspended | Stop released the context; Start must recreate it |
| E2E cannot hear audio | Fake device flags missing | Pass `--use-fake-device-for-media-stream` and the file flag |
